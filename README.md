## Free Cloudflare Pages deployment
1. Create a GitHub account/repository and upload the contents of this project.
2. Log in to Cloudflare.
3. Go to Workers & Pages → Create → Pages → Connect to Git.
4. Select the repository.
5. Framework preset: None.
6. Build command: leave empty.
7. Build output directory: /.
8. Deploy.

## Easy content and image updates
- Website text: edit `index.html`.
- Website styling: edit `assets/style.css`.
- WhatsApp links: edit `assets/app.js`.
- Images: replace files inside `assets/images/` while keeping the same filenames, or update the image paths in `index.html`.
- Social links: replace each `href="#"` with the real Instagram, Facebook and YouTube URLs.

No database is required for this static Cloudflare Pages website.
